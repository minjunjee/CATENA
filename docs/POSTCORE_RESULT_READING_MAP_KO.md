# CATENA post-core 결과 읽기 지도

이 문서는 완료된 post-core 결과와 현재 dependency 상태를 연결하는
탐색용 index다. 판정이나 claim을 새로 정의하지 않으며, 각 결과 문서와
동결 artifact의 기록을 우선한다.

전체 실행 요약은
[POSTCORE v6.2 결과 요약](POSTCORE_V62_RESULT_SUMMARY_KO.md)에서 먼저 볼
수 있다.

각 UTC run 안의 1페이지 결과 요약은
[E10–E21 run별 결과 요약 index](../artifacts/POSTCORE_E10_E21_RESULTS_SUMMARY_INDEX_KO.md)에서
한 번에 찾을 수 있다. 기존 E10–E16 index는 변경하지 않았다. Run 내부
summary가 없었던 E15a/E15b 초기 dry-run 두 건은 artifact 불변 원칙에 따라
각각 별도 sidecar 문서로 연결한다. 69개 completed run의 전체 coverage는
[요약 coverage 감사](POSTCORE_E10_E21_RESULT_SUMMARY_COVERAGE_AUDIT_KO.md)에
기록했다.

## E21 운영 이력

장시간 source run의 운영 상태 확인과 fresh retry에는
[detached tmux 운영 도구](E21_DETACHED_TMUX_OPERATIONS_KO.md)를 사용한다.
이 도구는 완료 판정 전에 exact 768-row grid, 네 checkpoint와 hash,
protocol/config hash 및 1페이지 summary 계약을 확인하며, active/completed
seed의 중복 실행을 차단한다. 외부 `SIGTERM`으로 끝난 partial run은
[운영 기록](E21_OPERATIONAL_RUN_LOG_KO.md)에 보존했고 aggregate source에서
제외했다.

## 세 문장 요약

완료된 controlled-reference 결과는 learned rank scaling, representation과
control basis의 한계, demand별 architecture freedom의 선택성을 지지한다.
E10과 E11의 원본은 계속 `NOT_OPENED`이며, 좁게 고정한 독립 repair만
`SUPPORTED`다. Structured sequence bridge와 continuation proxy도 등록
범위에서 `SUPPORTED`지만, official-backend, language-model 및 agent
claim은 닫혀 있다.
