## 중심 질문

## Regret 구분

- `R_span`: coefficient 범위를 무시한 structural direction deficit.
- `R_feas`: 실제 gate box 안에서의 최소 state error.
- `R_beh`: affected readout과 unaffected retention readout에서의 최소 error.

H1의 confirmatory predictor는 `R_beh`다.
