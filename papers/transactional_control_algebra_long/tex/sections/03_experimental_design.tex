\section{Experimental Design}
\label{sec:design}

\subsection{Evidence lineage}

The completed controlled core establishes behavioral reachability,
erase/write factorization, joint-diagonalization structure, and functional
mediation.  Post-core experiments test learned rank, representation/control
co-adaptation, the architecture lattice, and structured-sequence transfer.
Original protocols that were inconclusive or did not open a full claim remain
unchanged; separately frozen prospective repairs provide the results used
here.  Appendix~\ref{app:lineage} records the disposition rather than
retroactively relabeling an original run.

\subsection{Paired comparisons}

Comparisons use paired training seeds, matched data order and optimization
budgets, and a common maximal parameter surface where the protocol calls for
it.  Held-out operators or transactions provide evaluation data.  Independent
seed-level summaries are the inferential units; episode counts are not treated
as independent replications.

\subsection{Reproducibility contract}

Every plotted source path and SHA-256 digest is listed in
\texttt{data/source\_manifest.json}.  Figure generation verifies those inputs
before deriving plot-ready JSON and SVG.  This TeX scaffold imports numeric
tokens generated from \texttt{figures/RESULTS\_MACROS.md}; it does not
transcribe result values from prose.  Claim status comes from the frozen
report-level gates, not from visual inspection of a figure.
